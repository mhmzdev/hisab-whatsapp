# Sample ledger — a kiryana store

Fake numbers, generated by `tests/make_sample.py` through the same code path the agent uses. Two weeks of daily sales, stock bought on credit from Metro and for cash from Ali traders, one staff advance adjusted against salary, rent, electricity, and cash-to-bank transfers through `equity:transfer`. Rent and salaries are `~ monthly` rules, so the budget tab and forecast in hledger-dashboard have something to show.

Try it: point `config.yaml` at this folder (`ledger.path: ./sample-vault`) and ask *Metro ko kitna dena hai*, *is mahine vs pichla*, *balances*.
